# Interview Coach · 求职面试教练

基于真实证据的面试准备、模拟、复盘与能力提升 Skill。公共版 v1.1.1，不附带任何真实个人档案。

## 使用
下载或克隆本仓库，将文件夹命名为 `interview-coach`，保留 SKILL.md、references 和 assets 的相对结构，按所用 Agent 环境的说明导入 Skill 目录。各平台是否支持导入及长期保存，以其实际能力为准。

示例请求：“使用 interview-coach，分析这份 JD，并结合我本次提供的经历准备约90秒自我介绍。”

模拟面试一次一题；复盘按证据区分知识、表达及岗位匹配短板，输出可验收行动。不会推算录用概率或编造成果。

## 文件
- SKILL.md：工作流程与七项规则。
- references/：评价标准与知识地图。
- assets/：准备、复盘、STAR、历史记录与画像空白模板。
- examples/：虚构示例。
- SECURITY.md、CONTRIBUTING.md、CHANGELOG.md：隐私、贡献与版本说明。

## 隐私与限制
真实简历、录音、逐字稿及个人档案应放在仓库外的私有位置。private/ 已忽略，但忽略规则不能阻止误上传或清除 Git 历史。Skill 本身不提供自动持久化；仅在用户授权且环境具备读写能力时保存档案。

学习链接是入口，使用前核实有效性；未核实就注明。详见 SECURITY.md。许可证沿用仓库 LICENSE。
